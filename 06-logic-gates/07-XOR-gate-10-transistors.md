# XOR gate - 10 transistors combined
![Pasted image 20251103105845](../images/Pasted%20image%2020251103105845.png)
- when input is same `1, 1` or `0,0`, output is `0`
- when inputs are different (`1, 0`), then output is `1`
- XOR = either one switch or the other has to be on exclusively for the output to be on as well
- the XOR gate is made up with:
	- OR gate
	- NAND gate: that's an AND gate with a NOT gate at the backend 
		- a NOT gate just flips the output to its opposite
		- this means the NAND gate is output `0` only if both inputs are `1`, which is the opposite of the AND gate
	- AND gate
